## Quick start

```bash
# 1. Install dependencies
bun install

# 2. Push the Prisma schema to create the SQLite DB
bun run db:push

# 3. Copy .env.example → .env and fill in production keys (optional in dev)
cp .env.example .env

# 4. Start the dev server
bun run dev
# → http://localhost:3000
```

For production:
```bash
bun run build
bun run start
```

## Environment variables

All optional in dev. The site works with zero keys set; features progressively enable as you add them.

| Var | Purpose | When to set |
|---|---|---|
| `DATABASE_URL` | Prisma datasource | Always (default: `file:./db/custom.db` for SQLite) |
| `NEXT_PUBLIC_SITE_URL` | Canonical + sitemap + OG + JSON-LD absolute URLs | Production (default: `https://digiartha.com`) |
| `NEXT_PUBLIC_GA_ID` | GA4 measurement ID (`G-XXXXXXXXXX`) | When you want analytics — consent banner auto-shows |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | Cloudflare Turnstile client key | When you want CAPTCHA on the contact form |
| `TURNSTILE_SECRET_KEY` | Cloudflare Turnstile server secret | Pairs with the site key |
| `CRM_WEBHOOK_URL` | Webhook for new leads (HubSpot/Salesforce/Zapier) | When you want leads pushed to your CRM |
| `SMTP_URL` + `LEADS_TO_EMAIL` | SMTP for new-lead email alerts | When you want email notifications |

Get free Turnstile keys at https://dash.cloudflare.com/?to=/:account/turnstile

## Architecture

- **Framework**: Next.js 16 (App Router) + TypeScript 5
- **Styling**: Tailwind CSS 4 + shadcn/ui (New York)
- **Fonts**: Manrope (display) + Inter (body) + JetBrains Mono (numerics)
- **Motion**: Framer Motion (`whileInView` + reduced-motion fallbacks)
- **Forms**: react-hook-form + zod
- **DB**: Prisma ORM (SQLite client — swap to Postgres/MySQL for production)
- **3D approach**: CSS 3D + SVG + Canvas 2D for the infinity ribbon, particles, and glow (no heavy WebGL dependency — guaranteed build stability + instant no-WebGL fallback)
- **Brand palette** (from the logo): Ink Navy `#001331` → Cyan `#02A3FE` → Royal `#2E4BFE` → Violet `#7B3FFE` → Magenta `#E93BF2` → Coral `#FF544D` → Orange `#FF8E2D` → Amber `#FFB020`

## Guardrails respected (Master Prompt §14)

- Every non-verified number carries an `<Illustrative />` pill
- No third-party logos (Lucide icons + text names only)
- No rocket clichés (the logo's arrowhead is the only arrow motif)
- ISD relationship stays subtle (footer line only)
- Claims use "can / designed to / aims to" — never "guaranteed / #1 / best in India"
- One H1 per page; semantic HTML behind every canvas
- Mobile-first responsive; reduced-motion fallbacks; WCAG AA contrast
